# gbus562-coursework

## About

This repository contains my semester coursework for GBUS 562: AI Language Models at the University of Mary Washington. Each week's work is kept in its own folder.

## Weekly Work

1. **Week 1:** A self-contained Connect 4 game in [`week-01/connect-four.html`](week-01/connect-four.html), built with OpenAI Codex. Play against the computer or a second person; no installation or internet connection is needed to play.
2. **Week 2:** [`PromptLab`](week-02/prompt-lab.html), a single HTML tool for Anthropic Claude conversations and unedited Markdown exports, with four prompting experiments, their genuine exports, and a writeup in `week-02`.

### Play Week 1

Download or clone this repository and open `week-01/connect-four.html` in a modern browser. Choose a column with its numbered button or press a number key from 1 to 7. Connect four discs horizontally, vertically, or diagonally. Use **New game** to restart.

### Tool disclosure

Built with assistance from OpenAI Codex, including code generation and testing.
