# Coursework safety

Never write, print, commit, or export API keys or authentication tokens.
Read an existing API-Key.txt only from the folder above this repository, or
use ANTHROPIC_API_KEY from the current process. Never create a key file.
Always use the repository's .venv Python and install packages only in .venv.
Keep .venv, generated Chroma databases, caches, and secrets out of Git.
Preserve genuine model exports unchanged. Never invent an API response.
Do not incur paid API usage, publish, push, or submit without the user's authorization.
